# config/day23-period-06.py

6교시 초급 실습으로 작업 시작 전에 존재한 사용자 파일이다. 함수/클래스 정의는 없으며 모듈을 실행하면 바로 순회한다.

`rows`의 실제 초기값은 `[{"owner_user_id": 1}, {"owner_user_id": 2}]`이다. 모듈이 값을 정의하고 `row`는 순회 중 현재 사전이다. 비교 상수는 정수 `1`이다. 의사코드: 각 사전을 순회 → 소유자 ID가 1이면 `print(row["owner_user_id"])`. 직접 호출은 Python `print`, 정상 출력은 `1` 한 줄이다. DB나 로그인 상태를 읽지 않는 기초 예제이며 실제 보고서 view의 소유자 확인은 request.user.pk를 사용한다. 이번 작업에서는 파일을 변경하지 않는다.
