# ads/urls.py

`app_name = "ads"`이며 `urlpatterns`는 기존 combined views와 루트 include 구조의 Django URLPattern 목록이다. `path(route, view, name=...)`를 직접 호출해 아래 6개 경로를 모듈이 정의한다. URL 메서드/인증은 각 view에서 처리한다.

| 경로 | 직접 view | URL 이름 |
|---|---|---|
| advertiser/campaigns/ | views.campaign_view | ads:campaigns |
| advertiser/bids/ | views.bid_view | ads:bids |
| advertiser/events/ | views.advertiser_event_view | ads:web-events |
| api/media/decision/ | views.decision_view | ads:decision |
| api/media/events/ | views.event_view | ads:events |
| advertiser/reports/ | views.report_view | ads:web-reports |

작업 시작 전에 사용자가 6교시 보고서 경로를 추가했다. 교안의 `web_views.report_view`를 현재 프로젝트의 `views.report_view`로 연결한 기존 combined 구조를 보존한다. 이름과 공개 URL은 교안과 같다.
